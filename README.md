# ✈️ TravelMate AI

**Your AI-powered travel itinerary planner.**

TravelMate AI is a web application designed to help users plan trips with the assistance of Artificial Intelligence. It combines a React frontend with a FastAPI backend and Google's Gemini API to generate travel itineraries based on user-provided trip details.
